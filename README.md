# MYOGL Website

A simple starter foundation for the MYOGL website project.

## Structure

- `index.html` — main landing page
- `assets/css/style.css` — site styling
- `assets/js/main.js` — shared page initialization

## Run locally

From the project folder, start a simple static web server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000/ in your browser to view the site.
